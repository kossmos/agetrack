# Agetrack

Таймер возраста для игры "Денежный поток" (Cashflow). Визуализирует старение персонажа в процессе игры.

## Описание

Agetrack позволяет визуализировать течение времени в игре "Денежный поток". Каждый час реального времени соответствует определенному количеству лет жизни персонажа (по умолчанию 15 лет).

## Особенности

- Автоматический расчет финального возраста
- Прогресс-бар с отображением прошедшего и оставшегося времени
- Визуализация возраста с помощью эмодзи
- Темная и светлая тема оформления
- Адаптивный дизайн для мобильных устройств
- Сохранение игры и настроек после перезагрузки страницы
- Мгновенная пауза и продолжение, подтверждение сброса
- Автоматическая остановка на финальном возрасте
- Игры от 15 минут до 24 часов, с шагом 15 минут
- Офлайн-режим после первого открытия через HTTP/HTTPS
- Системная тема по умолчанию и управление с клавиатуры

## Использование

1. Приложение использует нативные ES-модули, поэтому открывайте его через HTTP, а не через `file://`.
2. Запустите локальный HTTP-сервер:
    - `npx serve .`
    - или `python3 -m http.server 8080`
3. Откройте приложение по адресу локального сервера (например, `http://localhost:3000` или `http://localhost:8080`).
4. Установите начальный возраст персонажа.
5. Укажите скорость старения (лет за 1 час).
6. Установите длительность игры.
7. Нажмите «Начать игру».

Во время игры параметры заблокированы. Пауза останавливает игровое время; закрытие страницы без паузы — нет. Для новой игры нажмите «Сбросить». Сохранение хранится только в текущем браузере. Если хранилище недоступно, приложение покажет предупреждение. Одновременно ведите игру в одной вкладке.

## Проверка

Для разработки нужен Node.js 22.14+ и `npm ci`. Само приложение работает без сборки и сторонних библиотек в браузере.

- `npm run check` — строгая проверка типов JavaScript через JSDoc, ESLint, Prettier, модульные тесты и проверка версии кеша.
- `npx playwright install chromium` — установка браузера для тестов.
- `npm run test:e2e` — браузерные тесты; отдельный тестовый сервер запускается автоматически на порту 8091.
- `npm run format` — форматирование исходников.
- `npm run cache:update` — обновление версии кеша после изменения файлов приложения; выполняйте после форматирования.

GitHub Actions выполняет проверки и браузерные тесты для push и pull request. При ошибке сохраняются трассировки Playwright.

## Структура и обновления

- `src/timer.js` — чистая модель таймера, переходы состояния, расчёты возраста и форматирование. Время передаётся аргументом.
- `src/storage.js` — проверка сохранений, версия формата и совместимость со старыми данными.
- `src/install.js` — установка PWA.
- `script.js` — привязка модели к интерфейсу.
- `tests/` — модульные и браузерные тесты, включая офлайн-загрузку и обновление PWA.

Service Worker предварительно кеширует весь набор файлов приложения. HTML и модули обслуживаются из одной версии кеша. Новая версия активируется после закрытия всех вкладок предыдущей версии; принудительного обновления во время игры нет. Для публикации загружайте весь набор файлов вместе с папкой `src/`. Версия кеша вычисляется по содержимому файлов и самого Service Worker.
